# 🌳 互動式電子家系圖與個案紀錄產生器 (Genogram & Record Generator)

這是一套專為第一線工作者打造的**現代化家系圖繪製與紀錄生成工具**。
結合直覺的圖形化操作與文字解析能力，解決實務上繪製複雜家庭結構（如重組家庭、多段婚姻）的痛點，並能把視覺化的家系圖一鍵轉換為專業的個案文字紀錄。

> **隱私優先**：全部在瀏覽器裡跑，沒有後端、不上傳任何資料。而且**預設不留痕跡** ——
> 每次開啟網頁都是一張乾淨的空白畫布，只有你按下「儲存案件」，內容才會存進這台電腦的瀏覽器。

## ✨ 功能總覽

### 📊 1. 智慧與自由兼具的畫布系統

* **原生世代排版**：輸入簡碼（如 `男女男`、`MFM` 或 `121`）即自動排列第一代到第三代的節點座標。
* **🧩 自由擴充區**：為「重組家庭」與複雜關係設計。固定四顆按鈕：
  **男性、女性、三角、生態圖**，點一下就在畫布上新增一個全新的獨立個體
  （不會覆蓋任何既有節點）。
    * **拖曳碰撞連線**：拖曳新增的獨立個體去碰撞目標，瞬間產生關係連線。
    * **磁吸平行對齊**：拖曳時自動吸附伴侶的水平高度。
    * **擴充子代完全體**：擴充關係生出的子代可再切換婚姻狀態與繁衍下一代。
    * **生態圖節點**：新增後預設連結案主，雙擊可編輯文字。
* **拖曳吸附與對齊線**：拖動節點靠近其他節點的水平／垂直線時自動吸附並畫出**灰色虛線**；
  拖父母到整排子女的正中央（或拖子女到父母中點）會吸上中線，虛線轉為**綠色**。
  子女人數變動時父母本來就會自動置中，這條中線是位置被拉亂後對回去用的。
* **畫布模式**：案主 `Q`／同住 `W`／年齡 `E` 三個互斥模式，一律「進入模式→點目標」。
  年齡模式下點人物直接輸入，填過的年齡就一直畫在節點上（沒有隱藏狀態，
  下載的圖也就一定帶著年齡）。
* **直覺微調**：狀態標籤點擊或滾輪切換婚姻／同住狀態、文字方塊可直接 Enter 換行。
  雙擊固定代表「刪除擴充個體」（男／女／三角），原生節點不受影響。

### 🧱 2. 快捷列表（常用狀態／關係標記）

固定在左側面板最上方（資料輸入面板下面）。「案主」（`Q`）「同住」（`W`）「年齡」（`E`）
三顆併排在列表最上排，都是「點按鈕（或按快捷鍵）進入模式→點目標」的畫布模式；
下面一排是 6 個最常用的狀態／關係標記——套用對象一律是**已存在**的人物節點或婚姻線，
不會在畫布上新增節點（新增獨立個體是「🧩 自由擴充區」的工作，見上一節）：

| 套用位置 | 符號 |
| --- | --- |
| 人物節點 | 死亡（打叉）／身心障礙（左半塗黑）／慢性病（左上四分之一塗黑） |
| 婚姻線 | 正向親密（雙線）／衝突（鋸齒線）／關係惡化（斜線佈滿的橫線） |

兩種套用方式效果完全一樣，且都是**套用／再套一次取消（Toggle）**：

* **拖曳**：把符號拖到人物節點或婚姻線上放開即套用，**只有放開的位置算數**，
  拖曳過程中經過的目標不會被動到；放開在不適用的地方等於取消。
* **鍵盤選取**：按 `A` 開/關選取狀態，`S`／`D` 把焦點切到左／右邊的符號（也可以直接點符號本身選取），
  選中後點畫布上的目標即套用，跟拖曳是同一套邏輯。

Toggle 規則：人物標記（死亡、身障、慢性病）套到已經有該標記的節點上會**移除**該標記；
婚姻線標記（正向親密、衝突、關係惡化）套用同一種樣式到同一條線上會把該線**還原成預設實線**，
套用不同樣式則直接覆蓋成新樣式。

面板上只放符號圖示本身（滑鼠停留顯示簡短名稱，不再彈出長文字說明框），符號依你用過的次數
排序，常用的會自己浮到最前面。全部可 `Ctrl+Z` 復原。

舊案件相容性分兩種情況：

* **仍會照常畫出來**：關係線的疏離、斷絕、暴力（存在 `lineAttrs`，見 `caseDoc.js`），
  以及流產、死產節點（`STANDALONE_TYPES`）。它們沒有面板入口，但舊檔打開仍完整呈現。
* **已完全移除**：精神疾病、生理疾病、藥酒癮、收養、寄養。程式碼裡已經沒有對應的渲染，
  舊案件若帶有這些標記，開啟後不會再畫出來。

`src/utils/symbols.js` 現在只收錄現行的 7 個符號（快捷列表 6 個 + 自由擴充區的三角），
說明書的「符號對照」也同步只列這些。

畫法依 [GenoPro 標準符號說明](https://genopro.com/genogram/symbols/)、英國 Oxfordshire Safeguarding
Children Board 採用的同一份文件，以及 McGoldrick, Gerson & Petry《Genograms: Assessment and
Intervention》建立的通用符號集。

### 🖼️ 3. 舊圖修補（Image Overlay & Patch）

手邊已經畫好的家系圖（掃描或手機拍的）不必重畫：

* 匯入 JPG／PNG／WebP 當**底圖**，可調**透明度**與**縮放**方便對位（長邊超過 1600px 自動縮圖）。
* **🧽 橡皮擦**：在底圖上拖曳即可抹掉舊線條；擦除模式下不會誤拖到節點，每一筆都能 `Ctrl+Z` 復原。
* 在舊圖上自由疊加積木符號、關係線與文字方塊，**下載時自動合併成一張新圖**。

### 📝 4. 智慧個案紀錄聯動

* **看圖說故事**：讀取畫布結構，翻譯成專業敘述（例如「案主為一般民眾…再婚，與案妻育有 1 子 1 女，案長子已婚…」）。
* **智慧稱謂計算**：自動寫出「案長女」「案么子」等相對稱謂。
* **前妻／前夫過濾**：略過與案主無關的旁系離婚紀錄。
* **可自訂標籤庫**（身分別、教育程度、障礙證明…）與**自由保存區**常用短語，皆存在本機。
* **跟著案件走**：案主基本資料與家屬補充資訊存在案件文件裡，會一起存檔、匯出、
  受 `Ctrl+Z` 保護，家系圖「重置」也會一併清空——換下一位個案不會殘留上一位的內容。
* **鍵盤連續填寫**：家屬欄位用 `Tab` 依序跳「居住地 → 職業 → 備註 → 下一位」，
  「主要聯絡人」的勾選框不在 Tab 順序內（一整排家屬只有一位是主要聯絡人，
  每張卡都停一次反而拖慢），要勾用滑鼠點。

### 💾 5. 存檔、時間軸與匯出

* **無痕畫布**：開啟網頁即空白，按下 **儲存**（第一次會請你命名）才建立案件、
  開始自動儲存後續變更並記錄時間軸。
* **時間軸**：每次儲存都在時間軸留一個節點，可命名、可還原回那個時間點；
  還原錯了能用 `Ctrl+Z` 復原這次還原。
* **多案件**：案件列的 **▾** 開啟已儲存的案件、點名稱改名。要開新的一份，重新整理即是乾淨畫布。
* **匯出／匯入 `.json`**：備份與交接用，匯入一律新增一份、不覆蓋目前內容；未儲存的草稿也能匯出。
* **⬇ 下載**：點按鈕直接存**高解析 PNG**（3 倍圖、白底、自動裁掉多餘白邊）；
  旁邊的 **▼** 收著 JPG、去背 PNG 與**列印／存成 A4 PDF**（借瀏覽器內建列印，不額外引入 PDF 套件）。
* **復原／重做**：只走鍵盤 `Ctrl+Z`／`Ctrl+Shift+Z`（面板上不放按鈕），一次拖曳算一筆歷史（上限 200 筆）。

### 🎨 6. 介面

* **燕麥侘寂風**：燕麥護眼底色、莫蘭迪低飽和色票、卡片不對稱圓角。
  低飽和不等於低對比 —— 所有文字對比度都在 WCAG AA（4.5:1）以上，實心按鈕白字達 5.5:1 以上。
* **說明收進 ⓘ**：卡片標題旁滑過即顯示操作說明，不常駐佔垂直空間；完整說明在右上角 **?** 說明書（按 `?` 也可開啟）。
* **雙頁籤狀態快取**：家系圖與個案紀錄間切換時，拖曳進度、編輯模式、表單文字都不會重置。
* **全螢幕（⛶）**：導覽列右上角一鍵收起瀏覽器介面，手機直立時多出來的高度相當可觀。
  iPhone 的 Safari 沒開放網頁全螢幕，點下去會改為引導「分享 → 加入主畫面」，
  之後從主畫面圖示開啟就是無網址列的獨立 App（已加入主畫面時 ⛶ 會自動隱藏）。
* **PWA**：備有 `manifest.webmanifest`、`apple-touch-icon` 與多尺寸 favicon，
  可安裝到桌面／主畫面；favicon 由 `tools/favicon/` 的腳本從單一主圖產生。

## ⌨️ 快捷鍵

| 按鍵 | 作用 |
| --- | --- |
| `A` | 開／關快捷列表的符號選取狀態 |
| `S` / `D` | 快捷列表選取狀態下，焦點切到左／右邊的符號 |
| `Q` | 切換「案主」標記模式 |
| `W` | 切換「同住」標記模式 |
| `E` | 切換「年齡」模式（進入後點人物即可輸入年齡） |
| `Ctrl`+`Z` | 復原 |
| `Ctrl`+`Shift`+`Z` 或 `Ctrl`+`Y` | 重做 |
| `Enter` | 「同住」點繪模式下，圈滿 3 點以上時閉合範圍 |
| `Esc` | 取消目前的拖曳或繪製 |
| `?` | 開啟使用說明 |
| 點擊／滾輪 | 狀態標籤點一下切到下一個狀態；停在上面滾動滾輪可雙向切換 |

## 🚀 快速啟動 (Local Development)

本專案採用 Vite + React，無後端、無資料庫。

```bash
git clone <your-repository-url>
cd <your-project-folder>
npm install
npm run dev        # 開發模式（HMR）
npm run build      # 產出 dist/
npm run preview    # 預覽建置結果
```

需要 [Node.js](https://nodejs.org/)（建議 18 以上）。

### 資料存放位置（都在瀏覽器 localStorage）

| Key | 內容 |
| --- | --- |
| `genogram-cases` | 案件索引：`{ activeId, list: [{ id, name, updatedAt }] }` |
| `genogram-case-<id>` | 該案件的完整文件（含底圖與擦除筆跡） |
| `genogram-snapshots-<id>` | 該案件的時間軸節點 |
| `genogram-symbol-usage` | 各符號使用次數（決定快捷列表排序） |
| `genogram-tags` / `genogram-savedNotes` | 紀錄產生器的自訂標籤與常用短語 |
| `genogram-doc` | 舊版的單一存檔鍵，只在第一次開啟時轉換進案件庫 |
| `genogram-recent-symbols` | 舊版的「最近使用符號」，會換算成使用次數後併入上面那個 key |

> 清除瀏覽器資料會一併清掉這些內容，重要案件請用**匯出**成 `.json` 保存。

## 📌 已知限制

* 底圖存成 dataURL 並跟著案件一起存進 localStorage，配額約 5MB。上傳時會自動縮圖並優先編碼成
  WebP（同品質下通常比 JPEG 再小 25–35%；瀏覽器不支援時安靜退回 JPEG／PNG），但若同時有多個
  含底圖的案件仍可能存不下 —— 儲存失敗會明確提示，可先移除底圖或改用 `.json` 匯出保存。
  （不用通用的 gzip 壓縮：JPEG/PNG/WebP 本身已是壓縮格式，再壓一次幾乎沒有空間可省，
  而要把壓縮結果存回 JSON 又得再 base64 一次，兩次膨脹反而比不壓縮還大——換編碼格式才是真的有效。）
* A4 列印／PDF 借用瀏覽器內建的列印功能，實際頁面邊界與字型渲染會依瀏覽器而略有差異。
* 家系圖符號在台灣實務上沒有統一標準，本工具的取捨與各來源分歧都記錄在 `src/utils/symbols.js`。
